# Escape Velocity Claude Plugin Marketplace

This is the [Claude Plugin Marketplace](https://code.claude.com/docs/en/plugins/create-marketplace.md) for Escape Velocity.

## Plugins

| Plugin | Description | Source |
|---|---|---|
| `mission-lock` | Analyzes a company's governing documents and assesses conditions related to the concept of "Mission Lock": qualities that affect how durably a company's mission is protected. These are mechanisms like Public Benefit Corporation status, purpose declaration and amendment thresholds. | [escape-velocity-co/mission-lock](https://github.com/escape-velocity-co/mission-lock) |
